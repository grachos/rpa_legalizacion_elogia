RPA LEGALIZACION ELOGIA - Instrucciones
=======================================

1. Copia esta carpeta completa (RPA_Legalizacion_Elogia.exe y .env.example) en tu PC,
   por ejemplo en Documentos\RPA_Legalizacion.

2. Abre RPA_Legalizacion_Elogia.exe. La primera vez se abre "Configuracion". Completa:
     - API key            (pidela a Sistemas)
     - SAP Productivo: Usuario (la contrasena es opcional: si SAP ya esta abierto
       con tu usuario no hace falta)
     - Asignacion Conductores (.xlsx): ruta del archivo (boton ...)
   Guardar. Puedes cambiarla luego con el boton "Configuracion".

3. Requisitos: SAP GUI con scripting habilitado y Excel instalado.

4. Uso: "Traer saldos de SAP (GR55)" -> fechas -> Generar -> revisar -> Exportar.
   Los resultados quedan en la carpeta "output" junto al .exe.

Nota: Windows puede mostrar "Windows protegio su PC" la primera vez por ser un .exe
sin firma digital. Haz clic en "Mas informacion" -> "Ejecutar de todas formas".
